# 0.8.8 File & Document Center — stage 1
Native Android SAF folder/file access, no broad storage permission. Session-only folder access, search/sort, multi-select files, create folder, rename, copy, provider-supported move, confirmed file deletion, share/open externally. File operations run on a single worker; no recursive folder copy/delete. Provider permissions and support vary; Android may restrict root Downloads and other folders. ZIP creation with flat selected files. Document Center from settings/downloads: native PdfRenderer page-by-page (seekable PDFs), bounded UTF-8 text/source/Markdown plain text, HEX preview, ZIP listing/extract individual entry, GZIP preview/extract. Archives use explicit output URI, never use archive entry paths as filesystem paths. 64 MiB decompressed scan/extraction budget; ZIP listing up to 500 entries. On extraction/write error partial output may remain; UI warns. No password archives, 7z/TAR/EPUB native viewer, syntax highlighting or recursive operations yet. External viewer available. No new dependencies. Test SAF providers, multi-select, file moves, denied permissions, PDF, ZIP limits, invalid names, canceled operations and downloaded URI sharing on actual Android. Signing and stable branch unchanged.
