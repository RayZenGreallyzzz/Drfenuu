# 0.8.3 Performance Center
Settings → Performance Center. Three presets modify existing browser display/media preferences; no CPU/GPU frequency changes. Economy also denies inaudible autoplay requests, balance is the previous default, performance removes app display preference and disables explicit inactive media suspension. Android/Gecko may still manage inactive sessions. Web video quality is not overridden. Snapshot is on demand: Android-wide memory, current process PSS (not entire GeckoView), battery temperature (not SoC), UID traffic since boot (not necessarily all isolated/VPN processes). Explicit confirmed background unloading excludes active tab, local/extension-owned pages, incomplete page loads, pending uploads, capture operations, and all pages while downloads are active. URL only is retained; form state, playback, scroll, session history can be lost. No automatic unload. Device tests: presets, app lifecycle, diagnostics, active transfers, unload and reopen a background page. No new permissions or dependencies. Stable branch and signing configuration unchanged.
