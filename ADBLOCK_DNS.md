# 0.8.4 AdBlock Pro and DNS Manager
The AdBlock Pro native settings panel discovers the official uBlock Origin extension by ID, offers opt-in installation through the existing Mozilla Add-ons XPI path and opens the original extension UI. EasyList, EasyPrivacy, custom rules and update management belong to uBlock Origin, not a new independent filtering engine. Gecko tracking protection remains separate and unchanged by default. Installation and extension dashboard must be tested on actual GeckoView.
DNS Manager persists system / fallback / strict mode and validated HTTPS URI, applies native GeckoRuntimeSettings TRR APIs on startup and selection, with rollback on synchronous errors. System is the default. Strict does not guarantee all device traffic or proxy resolution uses DoH; resolver bootstrap and Gecko exemptions may differ. No changes to VPN settings. Connectivity test opens example.org only, not an actual DNS leak test. No new Android dependencies. Device verification: resolver selection, restart, failed resolver, SOCKS/WireGuard interaction, uBlock install and filter panel, toggling tracking protection. No change to signing identity or stable branch.
