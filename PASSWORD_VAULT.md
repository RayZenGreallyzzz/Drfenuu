# 0.9.1 Password Vault (experimental)
Standalone manual local vault; Android Keystore AES-256-GCM with a device-authenticated time-bound key, unique generated IV per write, versioned envelope and AAD. Ciphertext only in separate private preferences, synchronous commit on worker. Key is not exported or silently replaced if ciphertext exists. Device secure lock required. API 30+ strong biometric or credential via system BiometricPrompt; API 26–29 system credential confirmation. UI session 45 seconds maximum, locks on leaving activity except credential confirmation, hides passwords by default, FLAG_SECURE on activity/dialog, disables view saved state and autofill. Up to 200 entries, 24-char SecureRandom password generator. No automatic website autofill, clipboard copy, export, cloud, recovery or passkeys. Java strings/IME can retain data transiently; not guaranteed memory erasure, not protection against compromised/rooted devices or malicious keyboards. Hardware-backed key not guaranteed. Biometric/PIN enrollment changes and key invalidation can make vault inaccessible; no automatic reset or deletion. Experimental: don't use as sole copy of important passwords until audited and device-tested. Verify unlock on API 26/29/30/35, auth cancellation, screen lock, timeout, background, encryption persistence, wrong key/tamper, interrupted save, key invalidation, screenshot policy and module disable. Stable branch and signing unchanged.
