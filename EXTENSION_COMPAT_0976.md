# 0.9.7.6 Extension Compatibility
Read-only manifest diagnostics, no archive execution. Bounded manifest parsing and candidate collection. A fixed bundled MV3 test extension with no host permissions runs synthetic messaging, storage, worker, WebAssembly, Blob/ArrayBuffer and manual TXT download tests. API presence is not proof of site or third-party compatibility. Downloads permission not requested. Existing isolated manual script bridge reconnects after disconnection and BFCache. No new privileged execution, network interception, arbitrary unsigned package installation, decryption, or quota bypass. Build and synthetic tests do not replace on-device validation.
