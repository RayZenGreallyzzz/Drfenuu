# 0.9.3 Backup Center
Portable explicit SAF .aebak encrypted envelope: magic/version, random 16-byte salt and 12-byte IV, PBKDF2-HMAC-SHA256 600k iterations, AES-256-GCM tag, header authenticated; 20 MiB plaintext cap. Password 12–256 characters, confirmation on export, no recovery or cloud. Export allowlisted appearance/performance/search language/download limit and module availability, bookmarks, optional saved workspace URLs and offline snapshots. No cookies, history, vault, signing keys, VPN, proxy/DNS, custom search engine templates, scripts, extension packages/config or downloads. Restore authenticates before parse, validates schema and bounds, lets user choose categories; settings off by default. Bookmarks merge within 200 cap; offline snapshots deduplicate and preflight 100/16MiB quota, rollback newly created files on IO failure best-effort. Preferences commit after snapshots; cross-store restore not fully transactional. Tabs restored to separate list (not automatically navigated), replaces previous recovered list only. MainActivity reloads preferences/bookmarks on return. Exported URLs/text may be sensitive; use strong unique passphrase. No security audit or device validation yet. Unit tests cover roundtrip, wrong password, tamper and randomized encryption. No new dependencies/permissions.
