# Delta updates
After stable signing is configured, retain exact signed ARM64 APKs. Generate a patch with `python3 tools/delta.py create OLD.apk NEW.apk update.aeb`. Verify with `python3 tools/delta.py apply OLD.apk update.aeb reconstructed.apk` and compare SHA256 with NEW.apk. Publish patches only if smaller than the full APK. On the tablet choose Settings > Update > open patch; Android confirms installation. Base APK must match exactly, target version must increase and package and signer must match. Full APK required for first stable signed install. No automatic update server or automatic patch publication yet. Tests use synthetic ZIPs, real APK/device verification still required.
