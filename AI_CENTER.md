# 0.9.4 AI Center — experimental
ChatGPT Web opens https://chatgpt.com/ in normal Gecko tab. Native chat uses explicit OpenAI-compatible /v1/chat/completions endpoint over HTTPS or unauthenticated HTTP loopback only; no redirects, no browser cookies, no tool execution, bounded request/response, no automatic retries. User configures model ID, endpoint and optional separate relay token for the current session. OpenAI key must NOT be entered in Android. No persistent credentials or chat history. Native client sends current text and visible session conversation after confirmation, including explicitly captured page text (max 24k chars, editable). Native networking is distinct from Gecko proxy/TRR/Tor; system VPN coverage depends on routing. Server response displayed as inert plain text. Cancel is best-effort; may incur charges. 
OpenAI relay example tools/ai_relay.py: run on personal trusted host with environment variables OPENAI_API_KEY, AETHER_RELAY_TOKEN (random >=32 chars), AETHER_MODEL (available model ID); binds 127.0.0.1:8765, single-user shared token, bounded input/output, fixed upstream Responses API, store=false (not a guarantee of zero provider retention). Put behind authenticated HTTPS reverse proxy with request/time/rate limits and restrict access; do not expose raw HTTP server. No server provisioned. API billing separate from ChatGPT plan. Ollama compatible endpoint requires trusted HTTPS reverse proxy for LAN, or HTTP loopback for on-device service; verify server supports max_completion_tokens (compatibility varies). Other vendors not directly integrated. Test on actual server/device: consent, API auth/limits, wrong endpoint, timeout, cancel, page changes, privacy settings. No new dependencies. 0.9.3 CI passed. Stable branch/signing unchanged.
