# 0.9.2 Offline Browser
Explicit text snapshot from current top-level HTTP(S) document using existing native port, correlated request token and current tab/URL checks; eight-second timeout. Article/main/body extraction, bounded text, excludes form elements, contenteditable and common hidden/script elements; not a guarantee that all sensitive content is excluded. No extra network fetch, no cookies/password form values collected, no HTML execution or subresources. Reader preview is temporary. Saved snapshot title, text, timestamp, URL without userinfo/query/fragment (path can still be sensitive) in app-private unencrypted atomic JSON. Up to 100 items and 16 MiB storage, 180k chars per capture; no automatic eviction. Native text library, search, font sizing, confirmed individual/all delete, explicit SAF TXT export with warning. Clearing browser history does not delete saved items. No full HTML/MHTML, images, video, interactive offline websites, encrypted library or full readability algorithm. No new dependencies/permissions. Device tests: updated bridge after app update, capture on same page/navigation, timeouts, private content warning, offline airplane mode, storage limits, delete/export, module disable. 0.9.1 build succeeded; signing unchanged.
