# 0.9.7.4 Auth and passwords
Native Gecko autocomplete callbacks, explicit secure save confirmation + Android credential auth, existing AES-GCM vault, HTTPS exact origin and same-origin form only. 45-second manually unlocked fetch, exact current origin/host, no global fetch. Browser entries visible in existing vault. Existing Android Autofill framework enabled on GeckoView; system service depends on device configuration. No CSV or global email suggestions yet, no cloud, no insecure HTTP or cross-origin form autofill. Login submission detection does not prove login success. Extension-owned auth tabs implement update and close, only for creating extension; normal tabs not silently closed/redirected. Own moz-extension callback allowed, no arbitrary protocols. Proton real login unverified; no cookies or security checks disabled.
