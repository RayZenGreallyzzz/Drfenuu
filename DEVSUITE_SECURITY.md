# 0.9.0 DevSuite Security — stage 1
New settings/DevSuite/Module Manager screen. Native offline Encoder Lab: Base64, form URL encoding, HEX, SHA-256, bounded input; no stored history or network. Local URL metadata (host, scheme, port, HTTPS scheme only, not TLS certificate validation). Optional Mozilla Add-ons install flows for official FoxyProxy Standard, Cookie-Editor, Wappalyzer; no bundling or auto-install. AMO Android compatibility verified on listing/version pages, actual GeckoView functionality not tested. FoxyProxy can conflict with existing DevSuite proxy; user must manually manage that before use. Cookie-Editor handles sensitive data; no automatic collection or export. Wappalyzer license is proprietary; no repackaging. Shodan opens official homepage only, no API or automated target submission. HackBar request editing and DotGit remain backlog, no automated scanning or repository retrieval. Existing permissions dialogs remain. Unit tests cover encoder roundtrips and invalid hex. No added Android permissions or dependencies. Stable branch and signing unchanged.
