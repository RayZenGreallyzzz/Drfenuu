# 0.8.9 Module Manager
Native catalog in Settings, persistent per-tool launch gates for Media Center, File Center, Document Center, Tor Engine, Eruda, xterm, CyberChef and v86. Default available to preserve previous behavior. Guarded activity entry and native launch paths; local extension tool callback checks preference again after async initialization. Disabling prevents future launches through these entry points, does not force-close existing sessions, unload injected scripts, uninstall assets, or constitute a security sandbox. Existing bridge, script engine and normal browser stay active. Network configuration is separate: actual WireGuard state, DNS mode, uBlock Origin panel, proxy and Gecko extension management; no network setting changed when resetting local availability. Performance Center reports process/device stats, not per-module RAM. No new dependencies or permissions. Includes compile fix for 0.8.8 FileCenter share Intent.setClipData (void return). Verify module toggles/restart, entry paths, opening/closing modules, unchanged proxy/VPN/DNS and XPI behavior on device. Stable branch and signing unchanged.
