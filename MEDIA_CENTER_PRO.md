# 0.8.7 Media Center Pro
Local LibVLC playback: user-selected SAF multi-file playlist (up to 100 entries, session only), previous/next, auto-next, repeat one/all, random next, speed 0.5–2×, LibVLC equalizer presets and off. Explicit Android PiP button; 16:9 window, no controls/polling overlay in PiP. PiP depends on Android support and settings. Audio focus requested before playback, paused on loss, released when leaving the visible player. Screen stays awake only while playing in full view. Existing hardware-decoder and refresh-rate options retained. No persistent playlist, foreground audio service, lockscreen notifications, web-video PiP or true background playback outside visible PiP yet. No new dependencies. Test actual device: local audio/video, multi-select, auto-next, repeated tracks, audio focus, PiP entry/exit/close, EQ/speed, decoder options, media URI grants. Stable branch/signing unchanged.
